## Implementation Details

### 1. Driver Service (`driver-service.ts`)

**Purpose**: Backend logic for driver CRUD operations using Devv Table API.

**Key Functions**:

#### `createDriver(input: NewDriverInput): Promise<DriverRecord>`

Creates a new driver in the users table.

**Input**:
```typescript
interface NewDriverInput {
  name: string;                    // Required
  email?: string;                  // Optional
  phone: string;                   // Required
  vehicleRegistration?: string;    // Optional
}
```

**Process**:
1. Generate temporary driver ID for tracking
2. Create payload with driver data
3. Call `table.addItem(USERS_TABLE_ID, payload)`
4. Fetch newly created driver using temporary ID
5. Return driver record

**Error Handling**:
```typescript
try {
  await table.addItem(USERS_TABLE_ID, payload);
} catch (err: any) {
  throw new Error(err?.message || 'Impossible de créer le chauffeur');
}
```

#### `getAllDrivers(): Promise<DriverRecord[]>`

Fetches all drivers from users table.

**Process**:
1. Get all items from users table
2. Filter by `role === 'driver'`
3. Map to `DriverRecord[]` format
4. Return list

#### `updateDriver(uid, id, updates): Promise<void>`

Updates existing driver information.

**Required Parameters**:
- `uid`: User's _uid field
- `id`: User's _id field
- `updates`: Partial<NewDriverInput>

#### `deleteDriver(uid, id): Promise<void>`

Soft deletes (deactivates) a driver.

**Process**:
1. Update driver status to 'inactive'
2. Set updatedAt timestamp
3. Log success/error

**Code Highlights**:

```tsx
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();

  if (!form.name || !form.phone) {
    toast({
      title: 'Champs manquants',
      description: 'Le nom et le téléphone du chauffeur sont obligatoires.',
      variant: 'destructive',
    });
    return;
  }

  try {
    setSubmitting(true);
    const driver = await createDriver(form);

    toast({
      title: '✅ Chauffeur créé',
      description: `Le chauffeur ${driver.name} a été ajouté avec succès.`,
    });

    navigate('/dashboard', { replace: true });
  } catch (error: any) {
    toast({
      title: 'Erreur',
      description: error?.message || 'Impossible de créer le chauffeur.',
      variant: 'destructive',
    });
  } finally {
    setSubmitting(false);
  }
};
```

## Troubleshooting

### Common Issues

#### 1. Error: "table not found"

**Symptom**: `Error 9016: project table f4eyoj5l0wzk not found`

**Solution**:
- Verify table ID in `driver-service.ts`
- Check table exists via `table_list` tool
- Confirm correct table ID is used

#### 2. Error: "_uid field required"

**Symptom**: `Error: _uid field is required`

**Solution**:
- Devv auto-sets `_uid` from logged-in user
- Ensure user is authenticated before creating driver
- Check `useAuthStore` has valid user

#### 3. Driver not appearing after creation

**Symptom**: Driver created but not visible in lists

**Solution**:
- Check driver has `role: 'driver'` field
- Verify `status: 'active'` is set
- Refresh dashboard to reload data
- Check query filters in driver lists

#### 4. Form submission stuck

**Symptom**: Loading state never ends

**Solution**:
- Check network connectivity
- Verify API endpoint is reachable
- Check browser console for errors
- Ensure try-catch in `handleSubmit`

#### 5. Navigation fails after creation

**Symptom**: Stuck on form page after success

**Solution**:
- Verify `navigate('/dashboard', { replace: true })` is called
- Check routing configuration in `App.tsx`
- Ensure user has access to dashboard
